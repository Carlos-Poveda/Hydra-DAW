# HYDRA DAW

Programa de desarrollo musical desarrollado en Java usando la librería de sonido de LWJGL.

("C:\Users\cpove\OneDrive\Imágenes\Capturas de pantalla\hydra.png")

## 🚀 Características
- Creación de sonidos usando el sintetizador
- Creación de bucles y melodías usando sonidos propios o externos
- Composición de canciones en la Playlist

## 🛠️ Tecnologías utilizadas
- **Java** (versión 17 o la que uses)
- **Eclipse IDE**
- *Otras librerías (ej. JavaFX, LWJGL)*
